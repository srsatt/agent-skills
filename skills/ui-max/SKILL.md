# UI Max

Use all four installed skills as one web UI workflow. Keep their scopes intact;
do not replace their current instructions with a summary.

## Workflow

1. Load and apply `$ui-design-foundations` to establish task flow, hierarchy,
   content measure, interaction conventions, and keyboard/focus lifecycle.
2. Load and apply `$avoid-ui-neuroslop` while choosing every visible string and
   empty state.
3. Before writing or changing HTML, CSS, or client-side JavaScript, load
   `$modern-web-guidance`, search for the task's concrete use cases, and retrieve
   every relevant guide. Follow its browser-support and fallback rules.
4. Implement or revise the interface without adding unrequested product scope.
5. Load `$web-design-guidelines`, fetch its current guideline source, and audit
   the changed files in its required `file:line` format.
6. Fix applicable findings, then repeat the foundation, keyboard/focus, and
   visible-copy checks before finishing.

For review-only requests, do not mutate files unless the user also asks for
changes. Report conflicts between source guidance, project conventions, and
requirements instead of silently choosing a materially different behavior.
